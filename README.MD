# ToDo Web App (React + Backend)

A full-stack To-Do application built using **React** for the frontend and a backend powered by **Express.js** and **MongoDB**. This app allows users to perform CRUD operations seamlessly, with data persistence and efficient state management.

![App Preview](https://i.postimg.cc/NjZMK3J2/To-Do-List-App.pngg)

---

## Features

- **Add Tasks**: Quickly add tasks to your to-do list.
- **Edit Tasks**: Update existing tasks effortlessly.
- **Delete Tasks**: Remove tasks once completed or unnecessary.
- **Backend Integration**: Persistent data storage using RESTful APIs.
- **Environment Configurations**: Secure sensitive data using `.env`.

---

## Tech Stack

### Frontend:
- React.js
- CSS
- axios

### Backend:
- Node.js
- **Express.js**: A minimalist web framework for Node.js.
- **Mongoose**: Elegant MongoDB object modeling for Node.js.
- **MongoDB**: Database for storing to-do tasks.
- **body-parser**: Middleware for parsing incoming request bodies.
- **dotenv**: Environment variable management for secure configuration.
- **cors**: Enable cross-origin resource sharing for seamless frontend-backend communication.

## Installation

### Prerequisites:
Ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v16+)
- [MongoDB](https://www.mongodb.com/)
- A package manager (npm or yarn)

   cd todo-web-from-react-with-backend
2. **Install the Packages**:

3. **Start the App**:
